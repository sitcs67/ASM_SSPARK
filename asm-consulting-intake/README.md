# asm-consulting-intake · 컨설팅 의뢰 접수 에이전트

컨설팅 **의뢰 메일**을 넣으면 일정 · 기업 · 담당 · 방문지를 뽑아 표로 정리하고, **고객사 폴더 뼈대 · 일정 파일(.ics) · 접수 알림 문구**까지 만들어 주는 Claude 업무 폴더입니다.

> 이 보관함의 메일과 결과는 모두 **가상 예제**입니다(가상 기업 '샘플전자', '예시건설', 주소는 `example.org`).
> 실제 기관 · 기업 · 사람 · 연락처 · 점검 리포트는 들어 있지 않습니다.

## 하는 일 (4단계)
```
의뢰 메일(.txt) ─▶ ① 정보 추출(표) ─▶ ② 고객사 폴더 ─▶ ③ 일정 파일(.ics) ─▶ ④ 알림 문구
                     ⏸ 눈으로 확인        + 점검 메일 매칭     ⏸ 등록 전 확인       (보내지 않음)
```
- 메일에 없는 값은 지어내지 않고 `확인 필요`로 남깁니다 (예: 요일이 날짜와 안 맞으면 표시)
- 비밀번호는 어떤 파일에도 적지 않습니다
- 메일 발송 · 캘린더 등록은 사람이 확인한 뒤에만 합니다

## 준비물
- Claude 데스크톱 앱 (Cowork 또는 Code 탭)
- 이 보관함을 내려받아(Code → Download ZIP) 압축을 풀고, Claude **새 채팅**에서 **폴더 연결** — `CLAUDE.md`가 바로 보이는 폴더
- 스킬로 쓰려면: `skills/asm-intake.zip`을 Claude 설정 → 기능(Capabilities) → 스킬에 올립니다 (내용은 `skills/asm-intake/SKILL.md`)

## 넣을 자료 — `예제자료/`
| 파일 | 용도 |
|---|---|
| `의뢰메일_샘플전자.txt` | 정보가 다 갖춰진 의뢰 메일 |
| `의뢰메일_예시건설.txt` | 정보가 빠지고 형식이 다른 메일 (`확인 필요` 시험용) |
| `점검메일_샘플전자.txt` | `[취약점 점검] 기업명` 메일 매칭 시험용 |

내 메일을 쓸 때는 메일 본문을 복사해 `.txt`로 저장해 넣습니다. 실제 메일은 이 보관함에 올리지 마세요.

## 시키는 말 한 줄
```
CLAUDE.md대로 '예제자료' 폴더의 의뢰 메일로 4단계(정보 추출 → 고객사 폴더 → 일정 파일 → 알림 문구)를 돌려줘.
```

## 결과가 쌓이는 곳 — `결과/`
| 파일 | 내용 |
|---|---|
| `접수요약.md` | 메일 전체를 한 표로 · 확인 필요 칸 수 |
| `고객사/[기업명]/` | `인터뷰&자료파일/` · `작업/` · `최종결과물/` · `작업내용기록.md` |
| `일정_[기업명].ics` | 더블클릭하면 캘린더에 들어가는 일정 파일 |
| `알림문구.txt` | 메신저에 붙여 넣을 5줄 요약 |

진행 기록은 맨 위 `작업일지.md`에 쌓입니다. 지금 들어 있는 결과는 예제 메일로 한 번 돌린 샘플입니다.

## 하면 안 되는 것
- 실제 의뢰 메일 · 점검 리포트 · 연락처를 이 보관함(공개)에 올리기
- `예제자료/` 원본을 고치거나 지우기
- 알림 · 메일을 에이전트가 직접 보내게 하기 — 초안까지만

## 함께 쓰는 에이전트
접수가 끝난 고객사 폴더에 인터뷰 메모와 점검 요약을 넣으면, 짝이 되는 **결과물 작성 에이전트**(점검표 → 결과보고서 → 제출 메일 초안)로 이어 쓸 수 있습니다.
